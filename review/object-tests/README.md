# Two synthetic object edits

Review the folded map (`paper.png`) and the book on a mat (`book.png`) independently. Both boards contain a synthetic starting scene, two anonymous delivered edits and native-resolution crops. Open each PNG at 100%. Read the task at the top, compare the full views first, then inspect the crops. The before image identifies where the edit started and which details belong to the scene.

The blind ZIP contains the rendered boards. To regenerate them locally, run `.\render\build.ps1` from this directory in Windows PowerShell. Keep the generator closed until the first read is recorded.

Copy the following for each board and send your completed observations before asking for the key.

> **Board**
>
> **Full-view judgment** — A, B, tie or neither. What made the difference?
>
> **Native-crop judgment** — A, B, tie or neither. Locate the mark or edge precisely.
>
> **Protected detail** — Name one original texture, shadow or edge and say whether each candidate preserves it.
>
> **Adequate to deliver** — A, B, both or neither.
>
> **Alternative and check** — What other detail could explain the mark? Identify a control area in the picture and describe what you would expect to see there if that explanation were true.
>
> **One actionable change** — If an edit needs work, state where and what to change while preserving which nearby detail.

An ambiguous or invisible difference is a valid observation. These boards test whether a reviewer can distinguish two deliberately different edits. They contain no model outputs or personal images.
