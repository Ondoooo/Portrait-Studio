## One experiment worth running

Choose the single finding most likely to change a review or delivery decision. Specify:

1. **Decision and evidence.** What should the operator do, and which panel, region or measurement motivates it?
2. **Competing explanations.** Give two plausible causes that predict different results. If the final pixels are identical, name the intermediate or metadata that would separate them.
3. **Smallest test.** Name the fixture, baseline, one change, what stays fixed, the saved stage to inspect and one unaffected control. Prefer an existing CPU test. Include a command or short pseudocode where useful.
4. **Decision rule.** State the observable pattern that would support each explanation, and the outcome that would make you stop. Include what you would do if the control regresses.
5. **Scope and cost.** Estimate the time or compute, and state what this synthetic test can establish about real photographs. Name the evidence still needed before changing a default.

If none of the results justifies an experiment, say which missing observation would change that judgment. A specific reason to close a hypothesis is a useful result.
